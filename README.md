 Contact Book

A simple **Contact Book application built using Python**. It is a command-line based project that allows users to manage their contact information easily.

## Features

* Create a new contact
* View contact details
* Update contact information
* Delete a contact
* Search contacts by name
* Count total contacts
* Input validation for age, email, and mobile number
* Simple command-line interface

## Technologies Used

* Python 3
* Python Dictionaries
* Functions
* Conditional Statements
* Loops
* Modules
* Regular Expressions

* Python 3.x
* Command Prompt / PowerShell / Terminal

No external Python packages are required.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/amiti4359-ui/Contact_Book.git
```

### 2. Open the Project Folder

```bash
cd Contact_Book
```

### 3. Run the Application

```bash
python main.py
```

On Windows, you can also use:

```bash
py main.py
```

## How to Use

After running the program, the following menu will appear:

```text
Contact Book App
1. Create Contact
2. View Contact
3. Update Contact
4. Delete Contact
5. Search Contact
6. Count Contact
7. Exit
```

Enter the number of the operation you want to perform.

### Example

To create a contact, select:

```text
1. Create Contact
```

Then enter the name, age, email, and mobile number when prompted.

## Data Storage

The contacts are stored temporarily using a Python dictionary while the program is running.

The current version does not use a database, so the contacts are removed when the program is closed.
