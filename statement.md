# Project Statement

## Contact Book Application

The Contact Book is a simple Python-based command-line application used to manage contact information.

The application allows the user to:

* Create a new contact
* View contact details
* Update contact information
* Delete a contact
* Search for contacts by name
* Count the total number of contacts

The project uses Python dictionaries to store contact details such as name, age, email, and mobile number. It is designed to demonstrate basic Python concepts such as dictionaries, loops, conditional statements, functions, user input, and modules.

## Objective

The main objective of this project is to create a simple and easy-to-use contact management system while applying basic Python programming and problem-solving concepts.
